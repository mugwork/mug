# Mug (Archived)

> **This project has been sunsetted and is no longer active.** Follow what the developer is working on now at [tylerberggren.com](https://tylerberggren.com).

---

[Mug](https://mug.work) was an AI automation platform for building deployed agents, real code workflows, & headless web surfaces for everyday business, integrated with any API, and accessed via email, SMS, & Slack — all built locally using Claude Code, Codex, & Cursor.

## What It Was

- **Custom Deployed Agents** — AI agents with persistent memory, skills, and 150+ model support via Cloudflare AI Gateway
- **TypeScript Automation Workflows** — Scheduled, triggered, and agent-invoked automation
- **Universal API Sync Connectors** — Connect any API, sync data into local SQLite
- **Headless Web Surfaces** — Forms, portals, dashboards configured with JSON
- **Automatic Slack App** — Every agent and workflow wrapped in a custom Slack app

## Tech Stack

- TypeScript, Hono, Cloudflare Workers/Durable Objects/R2/D1/KV
- Preact (Explorer UI), esbuild, SQLite
- CLI Agent Kit for Claude Code, Codex, & Cursor
